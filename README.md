# Swiggy Sales Analysis Dashboard

## Project Overview
This is my first tutorial-guided practice project in Excel and business analytics. I created an interactive sales dashboard using a Swiggy dataset to explore sales performance and key business metrics.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Interactive slicers and data visualization

## Dashboard Features
- KPI cards for sales, ratings, orders and average order value
- Monthly and daily sales trends
- Sales breakdown by food type
- State-level sales visualization
- Top cities by sales
- Interactive filters for categories, restaurants and months

## Skills Practised
- Organizing and analyzing data
- Creating calculated fields and summary metrics
- Building charts and interactive dashboards
- Presenting data in a business-friendly format
